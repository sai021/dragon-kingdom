# Firmware 0.3.0 beta 4 - unpublished local candidate

This candidate builds on beta 3, preserving chip-bound voltage calibration,
network locking, fixed parent password, power limits, All and saved-data layouts.
Stable v0.3.0 remains the beta-2-based shipping release. It does not read the
corrected C3 calibration. The exact shipped mix still needs the maker's inventory.

See [implementation and evidence](SHIPPING-IMPLEMENTATION.md),
[update compatibility and bridge transition](UPDATE-COMPATIBILITY.md),
[restore service](RESTORE-SERVICE.md) and [physical acceptance](PHYSICAL-ACCEPTANCE.md).
The current [parent guide](PARENT-GUIDE.md) describes shipping setup; unpublished
candidate features are explicitly labelled. Historical beta 3 notes are in
[the archive](history/beta-3-NEXT-RELEASE.md).

No candidate publication, hosted manual change or physical flash is authorized
by preparing these local files. Both target builds and software checks are recorded
separately from the still-required physical acceptance.
