Keep your dragon up to date

A computer can deliver the repair over your home Wi-Fi. No USB cable to the lamp and no opening the enclosure.

Main firmware: 0.3.1. Repairs the shipped beta-3 internet-update problem and improves dim lighting and low-brightness colour balance. Your saved dragons and settings are kept.

Download Dragon Kingdom Updater

Updater 1.1.0 is ready - two connection modes. Choose the download for your computer. Firmware is downloaded separately when you choose to update.

Windows 64-bit Mac: Apple Silicon Mac: Intel

Mac packages were tested on macOS 15; older macOS versions are not verified. Windows requires a 64-bit computer. This app has no Windows developer certificate or Apple notarization, so your computer may warn or block it. If blocked, use the phone-only route below; do not disable security protections. A managed school/work computer may require its administrator.

App release notes, source and SHA-256 checksums. Firmware files are separately signed and verified by both the app and lamp.

Choose how to connect

Keep the lamp on its normal bottom USB-C supply. Download and extract the updater ZIP for your computer. Windows: open Dragon Kingdom Updater.exe inside the extracted folder and keep its files together. Mac: open Dragon Kingdom Updater.app. Allow local-network access if asked.

Mode 1: Home Wi-Fi

  1. Connect the computer and lamp to the same home network, with internet on the computer. Set up home Wi-Fi first if needed.
  2. Choose Home Wi-Fi, then Check for updates and Find dragons. Select yours. If missing, use Add address with its webpage address. Guest networks, VPNs and isolated networks can prevent discovery; a reachable lamp on another subnet may need its numeric address.
  3. Enter parent password dragon123, review the installed and offered versions and choose Update selected dragon.

Mode 2: Dragon setup Wi-Fi (offline)

No home-Wi-Fi setup needed. Download first while the computer has internet, then connect directly to the lamp.

  1. While still on internet Wi-Fi, choose Download for offline use in the updater. Wait until it confirms the signed download is verified and saved. It prepares both board types and old/new update files; you do not choose a board or file yourself. This step does not install firmware.
  2. Choose Dragon setup Wi-Fi (offline). Power the dragon on. If its setup network is missing, switch its normal supply off and on before starting an update.
  3. In your computer's Wi-Fi menu, join your Dragon-Kingdom-XXXXXX network, password dragon123. Stay connected when warned there is no internet. The updater guides you but does not switch the computer's Wi-Fi automatically.
  4. Choose Connect to dragon. It checks 192.168.4.1. Select your dragon, enter parent password dragon123, review the versions and choose Update selected dragon. The transfer uses the saved signed files and needs no internet.

The prepared files survive closing/reopening the app, so you can reopen it while on the dragon network and select direct mode. If no complete verified download exists, return to internet Wi-Fi and prepare it first. For a later offline update, download fresh files while on internet again; preparing a new release keeps the previous complete set until the replacement is fully downloaded and verified.

In either mode: let the restart check finish

The app saves a private local backup before writing and checks the signed, board-matched file. It automatically chooses the repair file for beta 3. Keep power, Wi-Fi and the app connected, close other firmware uploads and avoid unlocking Parent settings in another browser tab during the transfer.

After a direct-mode restart, rejoin the dragon network if disconnected. If it disappears, rejoin home Wi-Fi: the app tries the previously reported home address and discovery for the same dragon. Direct mode allows up to five minutes for reconnection. Wait for validated startup and matching saved settings. Reopen the lamp page and check saved dragons, touch and lighting.

Backups stay in your computer's application-data folder, shown in the app; keep them private. Your home-Wi-Fi password is never entered into the updater. Both modes work for later compatible main releases, with your click required each time. After repair, the lamp's own Release update option is also available.

Phone-only repair: shipped 0.3.0 beta 3
  1. While your phone has internet, open this page. These repair files are only for shipped 0.3.0 beta 1–3 or old stable 0.3.0.
  2. Open your dragon's webpage, unlock Parent settings with dragon123 and open Firmware updates. Check its Detected board label: ESP32-S3 or ESP32-C3. If the label does not appear, stop and ask the maker; do not guess.
  3. Return here with phone internet and download the matching repair file below. On an iPhone, use Download linked file if tapping displays the file as text. Save the complete .dragon.json file in Files/Downloads; do not edit its contents.
ESP32-S3: beta-3 repair file ESP32-C3: beta-3 repair file
  1. Reconnect to home Wi-Fi and open the dragon page. If using the dragon's own setup Wi-Fi instead, rejoin Dragon-Kingdom-XXXXXX with password dragon123 and open http://192.168.4.1/.
  2. Unlock Parent settings, open Firmware updates and choose the downloaded file. Keep power connected and that page open while it uploads, verifies and restarts. Do not factory-reset.
  3. Wait about a minute, reconnect and reopen its page. Check the firmware reads v0.3.1, your saved dragons are present and normal controls work.

These explicitly named legacy bridges are signed repair packages. Do not select a raw .bin, a file for the other board, or the ordinary newer-format file on beta 3.

Phone file upload: beta 4 or newer

If your installed firmware is beta 4 or newer and older than 0.3.1, use the ordinary signed package for your detected board:

ESP32-S3 ordinary package · ESP32-C3 ordinary package

Follow the same file-upload and restart checks above. If already on 0.3.1 or newer, no installation is needed. Older 0.2.x devices require the maker's USB migration.

If the computer cannot find or update your lamp

Use the normal home network, not a guest/isolated network. A VPN or firewall may prevent discovery. Try Add address with the numeric IP shown on the lamp page. Follow your organisation's device rules; do not disable computer security.

If an update is interrupted before final verification, keep the lamp powered and check its page before trying again. Existing firmware remains until the signed image is complete. If the app cannot verify the restart, check its displayed version; do not assume it failed or repeat immediately. Keep the backup if settings differ and contact the maker.
