Keep your dragon up to date

Easy Update delivers the repair from a Windows or Mac computer. No USB cable to the lamp and no opening the enclosure.

Main firmware: 0.3.1. Repairs the shipped beta-3 internet-update problem and improves dim lighting and low-brightness colour balance. Your saved dragons and settings are kept.

Download Dragon Kingdom Easy Update

Easy Update 1.4.0 is ready - open, wait, then update all dragon setup networks. Choose the download for your computer. Opening the app checks and downloads the latest stable firmware automatically when internet is available. It installs nothing until you press an update button.

Windows 64-bit Mac: Apple Silicon Mac: Intel

Mac packages were tested on macOS 15; older macOS versions are not verified. Windows requires a 64-bit computer. This app has no Windows developer certificate or Apple notarization, so your computer may warn or block it. If blocked, use the phone-only route below; do not disable security protections. A managed school/work computer may require its administrator.

App release notes, source and SHA-256 checksums. Firmware files are separately signed and verified by both the app and lamp.

Choose how to connect

Keep the lamp on its normal bottom USB-C supply. Download and extract the updater ZIP for your computer. Windows: open Dragon Kingdom Easy Update.exe inside the extracted folder and keep its files together. Mac: open Dragon Kingdom Easy Update.app. Allow local-network access if asked.

Start here: offline mode (already selected)

Use this for a lamp that is not connected to home Wi-Fi. Beta 3 and current firmware open an AP at startup but close it 15 seconds after joining saved home Wi-Fi, even if a computer is attached. For a lamp already connected to home Wi-Fi, choose Home Wi-Fi mode. Simply power-cycling does not keep its AP open while the saved home network is available. The app refuses an AP firmware write if it can see the lamp is already home-connected.
  1. Open the app while this computer has internet. It checks the latest stable release and automatically downloads the complete signed offline set. Wait until ready. If the complete current release is already saved, it reuses it. Opening the app does not switch Wi-Fi or install firmware.
  2. Keep Dragon setup Wi-Fi (offline) selected and choose Find & update all dragons. This installs updates on nearby Dragon setup networks: use it only where all nearby dragons are yours to update. Allow OS Wi-Fi/location permission if asked. The app only lists Dragon networks; policy can require the manual option below.
  3. The app scans, then joins each network in turn, checks its lamp identity and updates only older firmware. Current/newer lamps are skipped without a downgrade. Parent password dragon123 is prefilled and editable. No selection or confirmation is required for each lamp.
  4. Keep normal power and the app connected. Wait for the results report showing each updated, current, newer or failed lamp. Each installation still saves a private backup and verifies signed board-matched firmware, startup and saved settings. If a lamp fails, the next is attempted after Wi-Fi restoration; if restoration fails, the batch stops.

Stop cancels safely before finalization. Once finalization starts, the current restart check finishes and remaining lamps are skipped. Do not disconnect power to stop an update.

Without internet at startup, a complete verified saved release remains usable, but the app says it may not be newest. With no saved release, connect to internet first. Reopen on internet or choose Download for offline use for fresh files before later offline updates.

Already connected? Use Home Wi-Fi

  1. Connect the computer and lamp to the same home network, with internet on the computer. Set up home Wi-Fi first if needed.
  2. Choose Home Wi-Fi, then Check for updates and Find dragons. Select yours. If missing, use Add address with its webpage address. Guest networks, VPNs and isolated networks can prevent discovery; a reachable lamp on another subnet may need its numeric address.
  3. The editable parent password is already filled in as dragon123. Review the installed and offered versions and choose Update selected dragon.

Reconnection and return to your original network

The app tries to reconnect to the same dragon after reboot and verifies firmware, startup and saved settings. It then tries to restore the computer's original Wi-Fi after each lamp. Direct-mode verification waits up to five minutes. When idle, you can also choose Return to original Wi-Fi; switching to Home Wi-Fi mode or closing the app also attempts restoration. Home passwords are not read or stored by the updater. OS policy, an unavailable network or saved-credential restrictions may require you to reconnect through the computer Wi-Fi menu.

The batch button scans once and handles every discovered setup network in turn. Lamps switched on afterward can be included by pressing it again. Home Wi-Fi and manual-connection modes retain the individual Update selected dragon button, with no extra confirmation.

Manual connection if Wi-Fi control is blocked
  1. On internet, choose Download for offline use and wait for verified files.
  2. Join your Dragon-Kingdom-XXXXXX network in the computer Wi-Fi menu, password dragon123. Stay connected without internet.
  3. In direct mode choose Manual connection to check 192.168.4.1. Select the lamp, review and update; parent password dragon123 is already filled in.
  4. Rejoin after restart if needed. If the AP disappears because the lamp joins home Wi-Fi, rejoin home Wi-Fi. The app looks for the same lamp. The 15-second restriction above applies to manual AP uploads too.

In either mode: let the checks finish

The app saves a private local backup before writing and verifies the signed board-matched file. It automatically chooses the repair package for beta 3. Close other firmware uploads and avoid unlocking Parent settings in another browser tab during transfer. Wait for validated startup and matching saved settings, then check saved dragons, touch and lighting.

Backups stay in your computer's application-data folder; keep them private. Home-Wi-Fi passwords are never entered into the updater. Both modes support later compatible main releases; for a later offline update download fresh files while on internet first. Firmware 0.3.1 remains the main release.

Phone-only repair: shipped 0.3.0 beta 3
  1. While your phone has internet, open this page. These repair files are only for shipped 0.3.0 beta 1–3 or old stable 0.3.0.
  2. Open your dragon's webpage, unlock Parent settings with dragon123 and open Firmware updates. Check its Detected board label: ESP32-S3 or ESP32-C3. If the label does not appear, stop and ask the maker; do not guess.
  3. Return here with phone internet and download the matching repair file below. On an iPhone, use Download linked file if tapping displays the file as text. Save the complete .dragon.json file in Files/Downloads; do not edit its contents.
ESP32-S3: beta-3 repair file ESP32-C3: beta-3 repair file
  1. Reconnect to home Wi-Fi and open the dragon page. Only if the lamp is not connected to home Wi-Fi, use its setup network instead: rejoin Dragon-Kingdom-XXXXXX with password dragon123 and open http://192.168.4.1/.
  2. Unlock Parent settings, open Firmware updates and choose the downloaded file. Keep power connected and that page open while it uploads, verifies and restarts. Do not factory-reset.
  3. Wait about a minute, reconnect and reopen its page. Check the firmware reads v0.3.1, your saved dragons are present and normal controls work.

These explicitly named legacy bridges are signed repair packages. Do not select a raw .bin, a file for the other board, or the ordinary newer-format file on beta 3.

Phone file upload: beta 4 or newer

If your installed firmware is beta 4 or newer and older than 0.3.1, use the ordinary signed package for your detected board:

ESP32-S3 ordinary package · ESP32-C3 ordinary package

Follow the same file-upload and restart checks above. If already on 0.3.1 or newer, no installation is needed. Older 0.2.x devices require the maker's USB migration.

If the computer cannot find or update your lamp

Use the normal home network, not a guest/isolated network. A VPN or firewall may prevent discovery. Try Add address with the numeric IP shown on the lamp page. Follow your organisation's device rules; do not disable computer security.

If an update is interrupted before final verification, keep the lamp powered and check its page before trying again. Existing firmware remains until the signed image is complete. If the app cannot verify the restart, check its displayed version; do not assume it failed or repeat immediately. Keep the backup if settings differ and contact the maker.
